*Patron CHAIN
En la funcion applyValidations() se hace us de este patron para poder ir ejecutando las validacion del
BusinessValidator
Se inicia el reduce con un Mono vacio Mono.empty() y el segundo parametro es la funcion de reducion,
se va ejecutando validacion por validacion, cada vez q acabe una continua con la otra y asi sucesivamente,
en caso de existir algun error lanza la excepcion q esta dentro de cada funcion q esta recorriendo
y el Mono::then permite q se realice de manera secuencial y no de manera asincrona

.reduce(
                        Mono.empty(),
                        (chain, validator) -> chain.then(validator.validate(input)),
                        Mono::then
                );

 **************
 .then = Es cuando quiero ejecutar algo
 .thenReturn = Es cuando quiero retornar algo
